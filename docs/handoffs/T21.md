## Fixture boundaries

The suite reuses only T19's existing grounded E interaction, Enter selection, menu and save helpers. It does not run T19's story branch fixtures. Player placement isolates each authored target and is not route traversal evidence. Eighteen ordinary exterior actors are cleared with disclosed 200-damage CombatComponent hits and normal persistent death hooks so combat cannot interrupt UI assertions; no enemy crowns are collected. The full-pack setup adds eleven spare patched coats through InventoryService. Quest completion states, quest flags and completed transaction receipts are never assigned directly. Physics, world adapters and the normal autosave scheduler remain active; explicit save/load uses real isolated test files.

The first test run exposed a production defect in stale inventory callbacks: a Take closure retained a freed quantity SpinBox, causing Godot errors after panel refresh. The root fixed InventoryPanel with revision/visible-mode checks, WeakRef quantity controls and context invalidation for take/buy/sell/claim/equip/consume actions. The final fixture retains same-source and cross-source regression coverage for that fix.
