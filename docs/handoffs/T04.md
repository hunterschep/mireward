# T04: First-person player
Status: IMPLEMENTED. Physics and rendered gear gates pass; sustained mouse-input inspection remains UNVERIFIED.

## Delivered
MirePlayer is a CharacterBody3D with a 1.8 m capsule, 0.32 m radius, 1.65 m eye, 45-degree floor limit, normalized ground movement, 4 m/s walking, 6 m/s sprint, acceleration, 30% air steering, grounded jump, gravity, and clamped mouse look. FirstPersonGear renders current weapon/shield, gloved hands, armor-dependent sleeves, and mail knuckle plates using VisualFactory. View gear does not cast detached world shadows.

PlayerVitals owns stamina spending/delay/regeneration against the session player snapshot. Later combat/recovery services consume this instance; do not add a second stamina regeneration loop. Sprint spends only after actual horizontal displacement. PlayerInput owns movement and pressed/held action queries with suppression until attack/heavy/block/interact/heal/jump release after modal/focus changes.

## Public integration
- Scene: scenes/player/player.tscn. One instance persists through travel.
- MirePlayer.camera, head, gear, controls, vitals; combat is a runtime Node reference filled by T06.
- spawn_at(position, yaw=0), set_input_enabled(bool), clear_input_edges(), apply_settings(), apply_look(relative).
- Camera vertical FOV reads SaveService.settings; look sensitivity is radians/pixel.
- guarding is supplied by the combat component. action_locked suppresses sprint/regen during committed actions.
- FirstPersonGear.pose(state, phase) delegates animation without controlling combat timing.
- Optional standalone fixture: scenes/player/movement_arena.tscn. Its own capture/Escape behavior is test-only; GameModeController owns production cursor/pause.
