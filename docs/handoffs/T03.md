# T03: Original low-poly visual toolkit

Status: VERIFIED for the T03 baseline. Final integrated visual review remains T23/T28.
Repository checkpoint: T03 owned working tree; root owns integration commits.

## Behavior delivered

R41/R52 visual baseline: 12 actor archetypes, all 23 registry gear/items, 15 architecture families, 30 prop families, 20 shared materials, 23 original SVG icons and five original 128px textures. All outputs are original local artwork with CC0 provenance in `docs/asset_manifest.md` and `assets/LICENSE.txt`.

Actors have articulated boots, greaves, knee joints, torsos, upper/lower arms, hands/gauntlets and role-specific helmets or hoods. Armed characters carry the expected sword, spear, mace and shield silhouettes. Rusk has a crested closed visor, heraldic kite shield and rank detail. The factory provides every required rigid animation pose; combat owns progress and timing.

Static architecture includes open door gaps, layered roofs, timber frames, window frames, masonry, arches, vaulted crypt, undercroft, bridge, ferry, camp and kiln. Story props have distinctive silhouettes and marks. The three chimes have color and one/two/three carved strokes so they remain distinguishable without audio or color alone. Banners cover all three aftermath choices. Every visual is collision-free.

## Changed files and contracts

Owned paths: `assets/` excluding audio, `scripts/art/`, `scenes/art/showcase.tscn`, `tools/generate_assets.gd`, `tests/unit/test_art.gd`, `docs/asset_manifest.md`, this handoff and `docs/handoffs/T03-buildings.md`. No shared core/autoload/project files changed.

Public API:

```gdscript
VisualFactory.actor(archetype: StringName) -> Node3D
VisualFactory.gear(item_id: StringName) -> Node3D
VisualFactory.building(family: StringName) -> Node3D
VisualFactory.prop(kind: StringName) -> Node3D
VisualFactory.pose(actor: Node3D, state: StringName, phase: float = 0.0, intensity: float = 1.0) -> void
VisualFactory.pose_gear(gear: Node3D, state: StringName, phase: float = 0.0) -> void
```

Actor direct pivots: Head, LeftArm, RightArm, LeftLeg, RightLeg. Arm descendants include Elbow/Grip. Coordinates use meters, feet at root and forward -Z. Idle/walk phase is radians; other pose phase is normalized 0..1. States: idle, walk/locomotion, windup, attack/sweep, thrust, block/guard, stagger, death, phase_two. Pose does not change yaw or translation. Gear states: idle, light, heavy, guard, parry_recoil, healing. Place gear under a mount that owns baseline position/orientation because pose_gear sets the gear root's rotation.

Static family IDs are enumerated in `ArtBuildings.FAMILIES` and `ArtProps.KINDS`, with complete lists in the manifest. Item names use the frozen registry. Chest props retain a direct `Lid` pivot for opening; other static geometry is merged by material. Lanterns provide visible flame geometry; world lighting remains the world owner's responsibility. Actors intentionally retain individual articulated pieces.

## Successor instructions

Prefer VisualFactory for runtime placement, or instantiate the stable reusable scenes under `assets/models/`. Gameplay collisions must be authored separately and respect door gaps. Consult the building handoff for floor heights and entrances; do not infer collision from overall mesh bounds, which would fill doorways and interiors. Use item registry IDs for first-person equipment. Preserve chest Lid when applying opened state. Apply persistent banner/chest/shrine changes in world adapters, not inside the visual factory.
