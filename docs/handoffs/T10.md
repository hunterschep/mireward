## Delivered

Greyfen is one 640 x 640 m exterior with the original nine landmark anchors, 26 hostile spawn records, four exterior entrance IDs and existing rest points preserved. The map now includes five authored road/footpath routes, 24 original art structures, three portal definitions, thirteen objective reservations, eight NPC station reservations, deep-water/bounds definitions and two orientation viewpoints. Castle, monastery and watchtower are deliberate taller silhouettes made from the original T03 art.

The ground uses deterministic faceted terrain in 64 chunks, rolling ground outside reserved routes, a deep millpond, and a steep physical mountain rim with perimeter collision. Roads and actor/objective/portal spaces remain level at the existing y=0 anchors. Seed 42817 places 320 trees and rocks outside routes, structures, stations, spawns and landmark sightlines. Decorative visuals cull at 85/160 m; ordinary structures at 220 m; major silhouettes at 700 m. Mesh resources are shared across decorative instances and static families remain material-batched.

Houses have shell collision with actual doorway gaps and threshold ramps. Gate/arch openings, the keep entrance and ferry deck are traversable by the real player. The helper's geometry and scale contracts are in `docs/handoffs/T10-landmarks.md`.

## Files and runtime contract

- `data/world/map.json`: existing data preserved, plus the `exterior` manifest and landmark discovery radii.
- `scripts/world/exterior.gd`: MireExterior world registry, loading and navigation readiness.
- `scripts/world/exterior_terrain.gd`: deterministic terrain/road/pond mesh and collision.
- `scripts/world/exterior_decor.gd`: seeded exclusion-aware decoration.
- `scripts/world/exterior_landmarks.gd`: landmark art and usable collision, delegated with exclusive ownership.
- `scripts/world/exterior_capture.gd`: short background GPU review fixture.
- `scenes/world/exterior/exterior.tscn`: production world-only scene.
- `scenes/world/exterior/exterior_nav.tres`: committed offline navigation mesh.
- `scenes/world/exterior/bake_manifest.json`: documentary generation report.
- `scenes/world/exterior/capture.tscn`: review fixture, absent from ordinary menus.
- `tools/bake_world.gd`, `tests/integration/test_exterior.gd`: generation and physical/navigation verification.

MireExterior exposes the agreed `scene_id: StringName`, `entrances: Dictionary<StringName,Transform3D>`, `rest_anchors: Dictionary<StringName,Transform3D>`, `entities: Dictionary`, `navigation_regions: Array[NavigationRegion3D]`, `navigation_synchronized` signal, and `is_navigation_ready() -> bool`. It contains no player, hostile actors, NPCs or gameplay container instances. `entities` starts empty for T17/root placement.

Additional read-only registries: `landmarks` maps IDs to art roots, `landmark_areas` maps IDs to Area3D trigger geometry, `objective_reservations` and `npc_reservations` map IDs to copied manifest rows, and `portal_definitions`/`hazard_definitions` expose copied definitions. Discovery areas use trigger layer64, player mask2 and `landmark_id` metadata. They do not grant discoveries themselves. Root's discovery adapter must subscribe, persist once, and refresh the map UI.

`navigation_cache_current()` verifies the current map SHA-256 against metadata embedded in the NavigationMesh. `navigation_error` explains a missing/stale cache or synchronization failure. No runtime rebake occurs. Readiness requires initialized map and region iterations, the correct region owning the closest point, and the start actually lying within 1 m of walkable navigation. This avoids treating an unrelated initialized map or a distant isolated polygon as readiness.

Positions are `[x,y,z]`; north is -Z. `routes` entries contain id, width and points. `structures` contain id, landmark_id, family, category, position, yaw, scale and collision mode. Objective/NPC reservations contain stable id, scene_id, position and radius; interior reservations are retained for their owning scene tasks. ## Navigation and reproduction

Pinned Godot: 4.5.2.stable.official.6ce3de25a. Bake from actual world-layer static colliders, using 0.5 m cells, 0.2 m height cells, 0.5 m agent radius, 2 m agent height, 0.4 m step allowance and 40-degree slope limit. The region configures its assigned map's cell size/height to match. Other scenes sharing that map must use compatible settings or replace the old region during travel.

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tools/bake_world.gd
godot --headless --path . --script res://tests/run_all.gd -- --suite=integration/test_exterior.gd
godot --headless --path . --script res://tools/bake_world.gd -- --verify-walks
```

Baking performs a connectivity check from the start to all nine landmarks before saving. It fails on missing navigation, disconnected destinations or file errors. Current output: 6,107 polygons and 4,075 vertices; the final bake/validation step took about 0.2 seconds after scene construction on this host. This is a build measurement, not an R48 frame-rate benchmark. Navigation and report files regenerated byte-identically in separate engine processes. Map changes require a rebake. The documentary JSON report is not a runtime dependency, so it needs no additional export include filter.
